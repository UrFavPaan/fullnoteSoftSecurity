1- Abuse Cases (II)
Generating abuse cases:
• Creating Anti-Requirements:
1. Provide insights into how
attackers will approach the
system's assumptions.
2. Applied throughout the
lifecycle.
3. Generated by security
analysts.
• Creating an attack model:
1. Explicit consideration of
well-known attacks.
2. Select attack patterns
relevant to the system.
3. Build abuse cases around
attack patterns.
4. Include anyone who can
gain access to the system.
