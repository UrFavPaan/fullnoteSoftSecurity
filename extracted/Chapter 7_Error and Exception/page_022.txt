Main Categories of Exceptions (Cont)
2. Unchecked Exceptions (Runtime
Exceptions)
• Definition: Exceptions that occur during
program execution, not checked at
compile time. Exceptions that compiler
does not force you to handle
• Example: NullPointerException,
ArrayIndexOutOfBoundsException
• Cause: Often due to programming errors.
• Security Concern: Attackers can exploit
unhandled runtime exceptions to crash
apps (DoS).
