# Software Security Interactive Notes

This folder contains a static GitHub Pages-ready study page based only on the provided CCSB5133 lecture PDFs.

## Files

- `index.html` - main interactive page
- `styles.css` - page styling
- `app.js` - notes, flashcards, quiz logic, and study tools
- `coverage.js` - generated slide-title coverage map
- `assets/security-study-map.png` - generated visual study map
- `extracted/` - local text/image extraction used to audit the PDF content

## Use Locally

Open `index.html` in a browser.

## Publish With GitHub Pages

1. Commit these files to a GitHub repository.
2. In the repository, open Settings -> Pages.
3. Choose the branch and root folder that contain `index.html`.
4. Save. GitHub Pages will serve the interactive notes page.

## Source Integrity

The notes intentionally avoid outside references. Simplified wording and memory aids are derived from the provided PDFs.
